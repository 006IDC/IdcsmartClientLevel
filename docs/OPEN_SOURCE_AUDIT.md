# 开源发布审计

本文记录 `IdcsmartClientLevel 1.6.3` 在公开发布前完成的自审计。它是维护者的
工程验证记录，不是第三方安全认证，也不能代替部署方对自身业务、财务和当地
法规的评估。

## 发布边界

- GitHub 源码包包含可读源码、测试、文档、CI、MIT 许可证和构建工具。
- V10 导入包只包含运行所需的 30 个文件，顶层目录固定为
  `idcsmart_client_level/`，可以上传到 V10，也可以解压到
  `public/plugins/addon/`。
- 两个公开包均不包含宿主核心源码、第三方插件源码、测试站地址、账号口令、
  私钥、签名服务配置、生产数据、日志或本机绝对路径。
- 插件不包含远程加载、遥测、后门入口、混淆载荷或动态代码执行；运行时没有
  Composer、NPM 或外部 CDN 依赖。

## 匿名化检查

发布工具对源文件及解压后的归档重复检查以下内容：

- 个人、组织、测试服务器和本机用户目录标识；
- 非 `example.com` 的示例网址和电子邮箱；
- 环境文件、数据库导出、私钥、证书及常见硬编码密钥形式；
- 远程包含、Shell 执行和动态求值等不应出现在插件中的能力；
- 符号链接、二进制夹带和意外的大文件。

结果：通过。示例网址统一使用 `https://example.com`，示例邮箱统一使用
`example.com`。

## V10 契约检查

- 稳定身份：目录、命名空间、插件类和数据库表前缀均保持
  `idcsmart_client_level` / `IdcsmartClientLevel`，升级不更换插件身份。
- 生命周期：普通安装和 `upgrade()` 均使用幂等迁移；重复升级不会重复建表、
  重复写种子或要求卸载重装。
- 数据边界：继续以四张 V10 兼容等级表作为等级和折扣事实源；推广、权益、
  收款及提现状态使用 16 张必要旁挂表，共 20 张插件相关表，不修改 V10 核心
  用户、商品和订单表结构。
- 模板兼容：提供通用、PC 和 Mobile 三份用户模板，三份文件逐字节一致；等级
  模板仍可读取既有等级关联字段。
- 提现边界：冻结结束后才发布到 V10 提现管理，审批和确认汇款使用同一官方
  管理入口；官方提现能力未安装或不可用时安全失败。
- 私有升级兼容：普通包与 Ed25519 签名升级包使用同一组 30 个运行文件；签名
  校验、旧版本原位升级、业务数据保留及重复 `upgrade()` 均已通过。签名包和
  私钥不属于公开仓库。

完整生命周期包含商品返利开关、观察期、权益二选一、提现冻结、官方待审核、
官方已通过未汇款、已实际汇款、部分/全额/重复/超额退款、多笔在途提现撤销、

验证环境清理。

本轮公开整理后的线上页面需要已登录的管理员或用户会话。发布审计未使用或
绕过真实账号登录，因而没有把“未登录时只看到登录页”误记为插件页面视觉
验收；页面交互由前端语法、模板一致性、接口生命周期测试和此前版本的登录态
回归共同约束。部署方仍应在自己的主题与登录环境完成桌面和移动端验收。

## 已知边界

- 当前实测基线是 V10 10.4.6；其他 V10 版本必须重新执行安装、升级和运行时
  测试，不能直接沿用本报告结论。
- 推广返利、提现、税务、隐私和反滥用规则因地区与业务不同，部署方需要自行
  配置并审核。
- 核心只提供订单级累计退款金额时，混合“返利/不返利”商品订单采用优先冲减
  可返利金额的保守规则，具体口径见架构与部署文档。
- 开源包不附带 V10、官方提现能力或任何商业系统授权。
